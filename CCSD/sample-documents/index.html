About these translations

The Chinese, Russian and Spanish editions of these documents were produced with Claude Opus 5.5, an AI model made by Anthropic, so that more residents can read them in their own language.

  1. Started from the original HUD documentsWe used the English originals published on HUD Exchange.
  2. Translated into each languageClaude Opus 5.5 translated each document into Simplified Chinese, Russian and Spanish, using one shared glossary so key terms read the same way across the whole collection.
  3. Rebuilt, staying true to the original designEach document keeps the original photos, colors, icons and layout; only the text was replaced. Page counts can differ because translated text runs longer or shorter. Web addresses, legal citations and acronyms such as HUD and PHA stay in English.
  4. Now being checked by native speakersNative speakers of Chinese, Russian and Spanish are reviewing each translation. If you spot a mistake or something that reads awkwardly, please email the Corrections contact on this page.
